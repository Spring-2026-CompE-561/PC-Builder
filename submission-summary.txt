PC Builder is a full-stack web application built with Next.js, ShadCN UI, Tailwind CSS, FastAPI, UV, and PostgreSQL. The website helps users create custom PC builds based on budget, use case, and preferences. Users can register, sign in, sign out, delete their account, generate guided builds from the home page, browse parts by category, open part detail pages, create manual builds from scratch, save builds, open saved build details, export builds, and delete saved builds. The frontend communicates with the backend through API calls for authentication, parts data, build generation, manual build creation, saved build management, build details, and account actions.

Main Functionalities:
- User registration, login, logout, and delete account
- Guided build generation from the home page
- Manual build creation from scratch
- Parts browsing by category
- Part detail pages
- Saved builds list and build details view
- Export build data
- Delete saved builds
- About and Privacy pages
