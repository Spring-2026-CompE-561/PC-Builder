PC Builder is a full-stack web application built with Next.js, ShadCN UI, Tailwind CSS, FastAPI, UV, and PostgreSQL. The website helps users create custom PC builds based on budget, use case, and preferences. Users can register, sign in, sign out, generate guided builds from the home page, browse parts pages, create manual builds from scratch, save builds, open saved build details, export builds as JSON, and delete saved builds. The frontend communicates with the backend through API calls for authentication, parts data, build generation, build creation, saved build management, and build details. For final integration, we also completed the saved-build flow, manual build flow, build details page, export/delete behavior, parts-page API fallback fix, and added About and Privacy pages for a more complete website experience.

Main Functionalities:
- User registration, login, logout, and authenticated account state
- Guided build generation from the home page
- Manual build creation from scratch
- Parts browsing by category
- Saved builds list and build details view
- Export build data as JSON
- Delete saved builds
- About and Privacy pages
